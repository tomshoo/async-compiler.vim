*async-compiler.txt* An async wrapper around the builtin |:make|.

Author: Shubanshu Tomar <tomarshubhanshu@protonmail.ch>

INTRODUCTION					*async-compiler.vim*

This plugin provides the ability to run compiler commands, set via 'makeprg',
and |:compiler|. But allows you to run those asynchronously. It does so by
running those commands inside a terminal buffer, and capturing the output
using the appropriate primitives present in vim and neovim.

COMMANDS					*:Compile*

:Compile[!] {args}

		    Compile the current project using 'makeprg'. It opens a
		    terminal buffer in a split and displays the output there.
		    Jumps to the first error on compilation failure, if <bang>
		    is not provided.

						*:ReCompile*

:ReCompile[!]
		    Re-run the last |:Compile| command. Semantically same as
		    re-running the last command from history.

						*:KillCompilation*

:KillCompilation[!]
		    Kill the compilation buffer. It will ask for confirmation
		    unless <bang> is provided, then stop the compilation job,
		    and close the terminal buffer.
